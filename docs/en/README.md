# ULW Sidebar Terminal

ULW opens one native shell terminal in the VS Code secondary sidebar.

## Usage

Open the secondary sidebar and select **ULW**. The terminal starts in the first workspace folder, or in your home directory when no workspace is open.

## Configuration

Configure the font, cursor, scrollback, shell executable, and shell arguments with:

- `ulw.fontSize`
- `ulw.fontFamily`
- `ulw.cursorBlink`
- `ulw.cursorStyle`
- `ulw.scrollback`
- `ulw.shellPath`
- `ulw.shellArgs`

See the [main README](../../README.md) for defaults and development commands.
